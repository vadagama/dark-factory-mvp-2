# ADR-0013: Инструментарий CLI оператора

## Статус

Принято (2026-09-22; дополнение к ADR-0008 — решение Q3).

## Основание

Notion-страница «CLI»;
`docs/analysis/2026-09-22-init-architecture-comparison.md` §4 (Q3), §5;
ADR-0008 (CLI-first, утилита `df`), ADR-0010 (плагины и точки расширения).

## Контекст

ADR-0008 фиксирует CLI-first и прикладной API ядра (6 команд), но не выбирает конкретные
библиотеки. Notion-страница сравнивает TypeScript-инструменты CLI: Commander, Clack, Ink,
OpenTUI, oclif — и предлагает: Commander + Clack для обычного CLI, Ink — для интерактивного
интерфейса с агентами; OpenTUI — оценить позже (проект в разработке, не production-ready);
oclif — если понадобятся независимо устанавливаемые плагины, добавляющие CLI-команды.

## Решение

- **Commander — каркас команд `df`**: команды, аргументы, флаги, справка
  (`df start / status / resume / cancel / submit-input / submit-decision`, ADR-0008).
- **Clack — интерактивные мастера**: вопросы, выбор, подтверждения, индикаторы выполнения;
  мастер настройки (`df init`), выбор harness/провайдера, запуск процесса.
- **Ink — позже, для интерактивного интерфейса с агентами**: история сообщений, поле ввода,
  список выполняемых инструментов, статусы агентов — при появлении сценариев `df chat` и
  живого наблюдения за попыткой. Browser-компоненты (HeroUI и др.) в Ink напрямую
  не переносимы: DOM у Ink нет.
- **OpenTUI — не для основного интерфейса**: допустим отдельный прототип панельной
  консоли позже; авторы обозначают проект как не готовый к production.
- **oclif — не сейчас**: возвращаться при появлении независимо устанавливаемых плагинов,
  добавляющих CLI-команды (ADR-0010).
- **Плагины фабрики отделены от механизма CLI-команд**: плагин деплоя или исследования
  работает и через терминал, и через будущую Console; CLI — одна из поверхностей,
  а не точка монтирования плагинов (ADR-0008, ADR-0010).

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| oclif как каркас | плагины, организация большого CLI, зрелые инструменты разработки | избыточен для 6 операторских команд MVP | вернуться, когда появятся плагины с CLI-командами |
| Ink с самого начала | единый React-подход для всех экранов | избыточен для операционных команд; UI-код там, где хватает текстовых ответов | добавляется вторым слоем по потребности (`df chat`) |
| OpenTUI | панели уровня терминальной IDE; используется в OpenCode | в активной разработке, не production-ready | только отдельный прототип позже |

## Последствия

- MVP: две зависимости `@dark-factory/cli` (`commander`, `@clack/prompts`) — лёгкий старт,
  быстрый мастер настройки.
- Разделение «логика команды / рендер» с начала: интерактивный слой (Ink) добавляется
  без переписывания команд.
- Console (ADR-0008, после MVP) — отдельная работа: терминальные и browser-компоненты
  не взаимозаменяемы.
- Пересмотр выбора (oclif, OpenTUI) — amendment к этому ADR.
