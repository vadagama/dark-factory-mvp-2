# ADR-0007: Spec Kit и baseline

## Статус

Принято (инициализация репозитория, 2026-09-22).

## Основание

Notion v4: [«Spec Kit и baseline» (стр. 5)](../sources/notion-v4/05-spec-kit-and-baseline.md),
[«Покрытие AI SDLC средствами Spec Kit» (стр. 9)](../sources/notion-v4/09-ai-sdlc-speckit.md);
анализ §4 (Q6), §5; не переносится ADR-054 (OKF-слой).

## Контекст

Фабрика должна вести спеки и держать согласованность знания о продукте. v1 использовал
OKF-слой (ADR-054); v4 заменяет его хранением рядом с кодом. Spec Kit уже установлен
(`.specify/`, `.agents/skills/speckit-*`).

## Решение

- **Spec Kit — SDD-слой as-is**: процедуры constitution / specify / clarify / plan /
  tasks / analyze / implement / converge исполняются агентом **через DSH** (этапы-инструкции
  с `instruction: provider: spec-kit`).
- **Workflow Engine Spec Kit не используется** — владелец процесса только ядро (ADR-0001).
- **Маршруты**: Assessment (оценка фичи), SDD (спецификация → реализация), BugFixing
  (`assessment.md` — код не меняется → `fix.md` → `test.md`; исходы verified/partial/failed).
- **Хранение рядом с кодом**: `.specify/`, `specs/<change>/`, `baseline/`,
  `.factory/product.yaml`, `baseline-impact.md` — в продуктовом репозитории, не в отдельной
  БД знания.
- **Документы с фронтматтером**: id, kind, status, introduced_by, relations.
- **Отдельный этап `baseline_update`**: изменение baseline — явный этап процесса с гейтом
  согласованности, не побочный эффект попыток.
- **Дублирование канонических источников запрещено**: документы ссылаются друг на друга
  (relations), копий канона нет.
- **Адаптер не вызывает LLM сам**: SDD-процедуры исполняются как обычные агентные попытки
  в DSH, с гейтами на их результатах.
- **OKF не переносится (Q6)**: базовые проверки согласованности (уникальность id,
  разрешимость ссылок, покрытие задачами) — check-типы гейтов (ADR-0005);
  `factory-okf` — по потребности после пилота.

## Последствия

- Знание о продукте версионируется вместе с кодом и ревьюится в MR.
- Согласованность поддерживается гейтами, а не отдельным каноническим слоем.
- Обновление Spec Kit — обновление файла-инструкций, не кода ядра.
