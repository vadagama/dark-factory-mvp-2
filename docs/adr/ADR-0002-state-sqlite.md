# ADR-0002: Состояние — SQLite как канон

## Статус

Принято (инициализация репозитория, 2026-09-22).

## Основание

Notion v4: [«Общая архитектура» (стр. 1)](../sources/notion-v4/01-general-architecture.md),
[«Рабочие окружения и параллельное выполнение» (стр. 6)](../sources/notion-v4/06-workspaces-parallelism.md),
[«Хранение состояния, CLI и будущая Console» (стр. 10)](../sources/notion-v4/10-state-cli-console.md);
анализ §4 (Q1), §5. Не переносится: ADR-053 (events.jsonl-канон); must-keep 8.

## Контекст

Q1: канон состояния — SQLite (Notion v4) или Git + `events.jsonl` с SQLite-проекцией (v1,
ADR-053). Нужен источник истины для Change/Run/StageRun/Attempt и журнала событий,
с восстановлением после сбоев.

## Решение

- **SQLite — канон оперативного состояния**: Change/Run/StageRun/Attempt/Workspace,
  вопросы и ответы, решения, внешние операции + компактный журнал событий.
- **Доменное изменение и событие пишутся в одной короткой транзакции**; длинных транзакций
  нет, транзакции не пересекают границы процесса.
- **Git — источник версий файлов** (код, артефакты), не состояния фабрики.
- **Идемпотентность по ключам**: `operationKey` (внешние операции), `executionKey`
  (исполнение Attempt), `commandId` (операторские команды). Повтор той же команды с тем же
  содержимым возвращает прежнюю квитанцию; с изменённым — конфликт.
- **Внешние операции**: статусы `prepared`/`unknown`; `unknown` блокирует слепой повтор —
  оператор/ядро сначала выясняет фактический результат.
- **Восстановление — backup + 8 сценариев** (resume/retry/reconcile), а не rebuild из
  журнала. Rebuild-тест из v1 — осознанная потеря; проекции/rebuild можно добавить позже,
  журнал событий остаётся в SQLite.
- **Один владелец состояния**: второй процесс run/resume — только через IPC к владельцу,
  параллельные писатели запрещены.

## Последствия

- Простая целостность и транзакционность без внешней БД; продукт переносим (файловая БД).
- Ограничение: SQLite — для одного писателя; горизонтальное масштабирование не цель MVP.
- Журнал событий хранится компактно, ретеншн по политике; полная replay-история не
  гарантируется.
