# ADR-0004: Декларативный процесс

## Статус

Принято (инициализация репозитория, 2026-09-22).

## Основание

Notion v4: [«Декларативный процесс» (стр. 3)](../sources/notion-v4/03-declarative-process.md),
[«Модульность, декларативность и плагинная архитектура фабрики» (стр. 12)](../sources/notion-v4/12-plugins.md);
анализ §5; заменяет ADR-052 (частично); must-keep 4, 9.

## Контекст

Процесс фабрики (этапы, гейты, политики, профили продукта) и роли агентов описываются
конфигурацией, а не кодом ядра. Нужен формат, который проверяем, версионируется и не
превращается в скрытый язык программирования.

## Решение

- **YAML-декларации** с `apiVersion: factory/v1`: `Process` (граф этапов), `Gate`,
  `Policy` (лимиты, риск-политики), `ProductProfile`.
- **Тексты — Markdown с фронтматтером**: `Role` (роль агента), `Instruction`,
  `Skill`. Формат совпадает с Agent Skills.
- **Схемы данных — JSON Schema** (draft 2020-12), упоминаются артефактами процессов.
- **Этап — контракт**: условия запуска, исполнитель, поручение, ожидаемые результаты,
  условия принятия.
- **Исполнители этапов**: `harness`, `command`, `integration`, `gate`;
  тип результата — `workspace-snapshot` (снимок рабочей области попытки).
- **Валидация**: `factory process validate` / `factory process explain` — процесс
  проверяется до запуска (разрешимость ссылок, схемы, лимиты).
- **Снимок конфигурации на Run**: Run исполняет ту версию процесса/ролей/схем, которая
  была на момент запуска (факт в SQLite, ADR-0002).
- **Этап сужает разрешения, не расширяет**: наследование прав — только downward.
- **Секреты — ссылки** (на env/секрет-хранилище), значения в декларациях запрещены.
- **YAML — не язык программирования**: без `eval`, выражений, вычислимой логики в
  декларациях; вся логика — в ядре (TypeScript).
- **Подключение Spec Kit**: этап-инструкция объявляется как
  `instruction: provider: spec-kit` (см. ADR-0007), без копирования процедур в ядро.

## Последствия

- Процесс читается и ревьюится как код; правки процесса идут через MR того же репозитория.
- Отсутствие вычислимой логики в YAML — сознательное ограничение: сложная условность
  оформляется этапами/гейтами, а не выражениями.
