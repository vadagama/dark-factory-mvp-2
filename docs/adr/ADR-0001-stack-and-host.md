# ADR-0001: Стек и хост фабрики

## Статус

Принято (инициализация репозитория, 2026-09-22).

## Основание

Notion v4: [«Общая архитектура» (стр. 1)](../sources/notion-v4/01-general-architecture.md),
[«Контракт с DSH» (стр. 4)](../sources/notion-v4/04-dsh-contract.md),
[«Разработка, версионирование и откат релизов фабрики на DSH» (стр. 11)](../sources/notion-v4/11-releases.md);
анализ `docs/analysis/2026-09-22-init-architecture-comparison.md` §4 (Q2), §5.
Заменяет/переносит: ADR-051 (частично), ADR-052 (частично).

## Контекст

Dark Factory v4 — агентная фабрика разработки: агентные попытки исполняются движком DSH,
процесс задаётся декларативно, ядро остаётся тонким и детерминированным. Открытый вопрос Q2:
ядро — отдельное приложение или Cordis-сервис внутри DSH.

## Решение

- **Отдельное приложение (Q2)**: ядро — самостоятельный Node-процесс, не встраивает Cordis
  в собственное ядро. Cordis — возможная форма поставки в будущем, не сейчас.
- **Стек**: TypeScript (ES2023, NodeNext, strict), Node 24 (`.nvmrc`), pnpm-воркспейс
  (`packages/*`, `plugins/*`), zod — для канонических контрактов (`@dark-factory/contracts`),
  Vitest — для тестов.
- **Один процесс, девять слоёв** (не микросервисы): состояние и транзакции; планирование
  (граф этапов); контракты ядра; адаптеры; исполнение; агенты (в DSH); гейты; операторский
  интерфейс; декларативный процесс.
- **DSH — зафиксированный движок исполнения**: доступ только через TypeScript SDK, скрытый
  в `@dark-factory/dsh-adapter`. Ядро не импортирует SDK напрямую. Один Attempt → одна
  сессия DSH.
- **Не всё через DSH**: тесты, схемы, worktree и другие детерминированные операции
  выполняются ядром напрямую; DSH — только агентные попытки.
- **Workflow Engine Spec Kit не используется**: Spec Kit подключается как SDD-слой
  (см. ADR-0007), его движок workflows не управляет конвейером.
- **Нет второго LLM-оркестратора**: единственный владелец процесса — ядро.

## Последствия

- Простота MVP: один процесс, локальный IPC; Cordis/встраивание отложено.
- Смена движка исполнения возможна заменой адаптера, но DSH зафиксирован для MVP.
- Изоляция типов: SDK DSH не «протекает» в доменные типы ядра; граница —
  `packages/plugin-api` + адаптер.
